# Riju Das

**AI Engineer and Data Scientist | LLM Agents, MCP, RAG, Model Evaluation, MLOps**

I build, evaluate and deploy AI systems. I successfully defended my PhD in Computer Science at University College Dublin in November 2026, with research on visual emotion understanding using vision-language models. I am based in Dublin, Ireland.

[Portfolio](https://rijju-das.github.io/my_profile) · [LinkedIn](https://www.linkedin.com/in/riju-das-058b3295/) · [Google Scholar](https://scholar.google.com/citations?user=RPJi3FAAAAAJ)

## Applied AI projects

- **EvidenceGate**: the facial-expression recognition model from my PhD, deployed as a tested, monitored service on AWS Lambda. It has an evidence gate that abstains when the evidence is weak, a CI/CD pipeline with GitHub Actions and CloudFormation, an MLflow model registry, and an MCP server so that AI agents can call it. Details are on my [portfolio](https://rijju-das.github.io/my_profile).
- **[Databricks Agent Lab](https://github.com/rijju-das/databricks-agent-lab)**: a tool-calling agent on Databricks with Unity Catalog SQL functions as tools, AI Search retrieval, and MLflow tracing and evaluation, on synthetic card-transaction data.
- **[Seekcrew](https://github.com/rijju-das/seekcrew)**: open-source LLM agents for job search, with JSON-schema tools, input validation, tracing and an evaluation harness that measures quality, cost and reproducibility.

## Research code

- **[Student-Engagement](https://github.com/rijju-das/Student-Engagement)**: student engagement recognition from facial and behavioural features extracted with OpenFace and MediaPipe (Neural Computing and Applications, 2025).
- **[Frame-level-student-engagement](https://github.com/rijju-das/Frame-level-student-engagement)**: frame-level engagement classification in lecture videos through knowledge transfer (Applied Intelligence, 2024).
- **[Automatic-emotional-image-captioning](https://github.com/rijju-das/Automatic-emotional-image-captioning)**: image captions that include the emotion of the main person in the image (Multimedia Tools and Applications, 2024).
- **[Estimation-of-valence-and-arousal](https://github.com/rijju-das/Estimation-of-valence-and-arousal)**: joint estimation of emotion categories and valence-arousal from facial images (IMVIP 2024).
- **[AdMoteNet](https://github.com/rijju-das/AdMoteNet)**: multimodal emotion understanding in advertisement images (IMVIP 2025).
- **[Reverse_SMOTE](https://github.com/rijju-das/Reverse_SMOTE)**: oversampling for class imbalance guided by reverse nearest neighbours (IEEE ICOSEC 2020).
